# Calculator

A simple calculator built with plain HTML, CSS and JavaScript. No frameworks or build step.

## Use it
Live: https://tzviungar.github.io/calculator/

Or open `index.html` in a browser.

Keyboard shortcuts: numbers, `+ - * /`, `Enter` for equals, `Backspace` to delete, `Esc` to clear.

### Currency converter
Tap **💱 Currency** to convert the number on the display between about 30 currencies. Rates are the European Central Bank's daily reference rates, from the free [Frankfurter API](https://frankfurter.dev). **Use result** puts the converted amount on the display so you can keep calculating with it. Converting needs an internet connection.

## Files
- `index.html`: the layout and buttons
- `style.css`: the look
- `script.js`: the calculator logic
